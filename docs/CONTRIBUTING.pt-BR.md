# RadioAtlas BR — Português

Convite aberto: profissionais, estudantes, pesquisadores e tradutores podem colaborar por issues e pull requests. Contribuições devem ser legais, autorizadas e verificáveis.

1. Open an issue describing the intended improvement.
2. Fork and create a feature branch.
3. Use public, owned or synthetic inputs only.
4. Run `python3 -m unittest discover -s tests -v`.
5. Update PT-BR, EN and ES language variants.
6. Submit a pull request and describe test results.

Maintainer and creator: Chris Cruz (@h4ckd4d).
